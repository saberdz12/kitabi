# مشروع كتابي - النسخة التجريبية

## محتويات المشروع
- `index.html`: هيكل الصفحة.
- `style.css`: التصميم المتجاوب.
- `app.js`: البحث والتصنيفات وتفاصيل الكتب التجريبية.
- `manifest.webmanifest` و`service-worker.js`: أساس تثبيت الموقع كتطبيق ويب تقدمي (PWA).
- `database/schema.sql`: مخطط أولي لقاعدة بيانات Supabase.

## تشغيل المشروع من هاتف Android
1. افتح Replit من المتصفح وأنشئ مشروعاً جديداً من نوع HTML, CSS, JS.
2. ارفع ملفات هذا المجلد أو انسخ محتويات الملفات إلى الملفات المناظرة.
3. اضغط Run أو افتح رابط المعاينة.
4. جرّب البحث والتصنيفات وفتح تفاصيل الكتب.

## تثبيت الموقع على الهاتف
بعد نشر المشروع على رابط HTTPS:
1. افتح الرابط في Chrome.
2. افتح قائمة المتصفح.
3. اختر "إضافة إلى الشاشة الرئيسية" أو "Install app" إذا ظهر الخيار.

## ملاحظات مهمة
- الكتب المعروضة بيانات تجريبية وليست كتباً فعلية.
- لا توجد مصادقة أو قاعدة بيانات متصلة في هذه النسخة.
- ملف SQL مخطط أولي؛ يجب مراجعته واختباره وضبط صلاحيات الإدارة قبل إطلاق الخدمة.
- PWA يعمل كتطبيق ويب قابل للتثبيت، لكنه ليس بديلاً كاملاً عن تطبيق Flutter أصلي.
- أضف فقط ملفات الكتب التي تملك حق توزيعها أو التي تسمح تراخيصها بذلك.
